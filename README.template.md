## How to write an NSFW image prompt

```
[Shot type] of [an adult, age range, look] + [wardrobe or state] + [pose / action]
+ [setting] + [light: source and direction] + [lens / film look] + [mood or style]
```

| Do | Don't |
|---|---|
| "Photorealistic boudoir portrait of a woman in her early 30s…" | "Hot girl, sexy, beautiful" |
| Name the light source and side: *window light from the left* | "Good lighting" |
| Name a lens or film look: *85mm, shallow depth of field, 35mm film* | "High quality, 8k, masterpiece" |
| Describe fabric: *black lace, ivory silk, sheer mesh, satin* | "Sexy outfit" |
| One pose, hands doing something: *hands on her knees*, *holding a coffee cup* | Complicated poses with both hands in frame |
| State adult age every time: *in her 30s*, *adult man in his 40s* | Descriptors that suggest youth |
| Put exact words in quotes for signs and covers | Expect the model to invent correct text |

Qwen Image and Seedream prefer natural sentences over tag lists. Keep negative words out of the main prompt (writing "no clothes" can confuse models; describe what *is* there). Qwen Image 3.0 Pro accepts a `negative_prompt` field if you need one.

## NSFW image to prompt

Want to recreate the look of a reference image? Describe it in this order and you have a prompt:

1. **Shot:** portrait, full body, close-up, overhead, POV, wide.
2. **Subject:** adult, age range, build, hair, expression. Never describe a real, identifiable person.
3. **Wardrobe:** garment, fabric, color, how it's worn (open, off the shoulder).
4. **Pose:** where the hands are, where the weight is, where the eyes look.
5. **Setting:** room, props, time of day.
6. **Light:** source, direction, color temperature, hard or soft.
7. **Camera:** lens length, depth of field, film stock or phone look.
8. **Style:** photoreal, editorial, film noir, anime (then add the LoRA), oil painting.

Or paste your written description into the [LLM prompt writer](#let-an-llm-write-your-prompts) below. To keep a character or outfit exactly, skip the prompt and use an [editing prompt](#uncensored-image-editing-prompts) with the image itself as the reference (only for yourself, consenting adults or generated characters).

## Cheat sheet

**Lenses and camera**

| Write | Effect |
|---|---|
| `85mm, shallow depth of field` | Flattering portrait, blurred background |
| `35mm film` | Natural, documentary, slight grain |
| `50mm` | Neutral, true-to-eye perspective |
| `macro` | Extreme detail: lace, jewelry, skin |
| `wide shot, 24mm` | Environment, figure small in frame |
| `overhead / top-down` | Graphic, flat, great for beds and baths |
| `POV` | First-person, personal |
| `smartphone photo, slight grain` | Believable creator content |

**Light**

| Mood | Write |
|---|---|
| Soft, romantic | window light, sheer curtains, golden hour |
| Dramatic | single hard key light, deep shadows, chiaroscuro |
| Noir | slatted light from blinds, black and white |
| Warm, intimate | candlelight, firelight, tungsten lamp |
| Glam | softbox, beauty dish, high key |
| Neon | magenta and cyan neon, wet reflections |
| Backlit | rim light, silhouette, glowing edges |

**Looks and styles**: editorial fashion photography · boudoir photography · fine-art nude photography · Kodachrome / Portra 400 film · black and white · film noir · 1950s pin-up · oil painting · watercolor anime (LoRA) · storybook anime illustration (LoRA) · cyberpunk.

**Realism**: natural skin texture · visible pores · slight film grain · imperfect lived-in room · mixed practical light. Avoid "flawless", "perfect skin", "8k", which push toward a plastic look.

## FAQ

### What is the best AI model for NSFW images?
In SpicyAPI's published tests: **Qwen Image 2.1** (Spicy Index 73, Freedom 96.3, from $0.024) for most work, **Qwen Image 2.1 LoRA** (#1 on the image index) and **MiniMax H3 Image LoRA** (Freedom 100) for your own styles, **Seedream 5.0 Pro** for a photographic finish, **Qwen Image 3.0 Pro** when the image has text, and **Z-Image Spicy** for the cheapest drafts. See [Best models for NSFW images](#best-models-for-nsfw-images).

### How do I write a good NSFW AI image prompt?
Write full sentences in this order: shot, adult subject with age, wardrobe and fabric, pose, setting, light, lens, style. Name the light source and a lens; skip "8k masterpiece". See [How to write an NSFW image prompt](#how-to-write-an-nsfw-image-prompt).

### Can I edit a photo with an uncensored AI image editor?
Yes, with Qwen Image 2.1 Edit: send 1–10 reference images and one instruction ("change the outfit to…", "relight to candlelight…"). Only edit images of yourself, consenting adults or generated characters; "undressing" photos of real people is prohibited. See the [editing prompts](#uncensored-image-editing-prompts).

### How do I make anime or hentai-style images?
Use Qwen Image 2.1 LoRA with an open anime LoRA (the storybook-anime and watercolor-anime LoRAs used in SpicyAPI's own examples), start the prompt with the LoRA's style phrase, and design every character as an adult. See [Anime & Illustration](#anime--illustration-qwen-image-21-lora).

### Do these prompts work in Stable Diffusion, ComfyUI or Midjourney?
The sentence-style prompts work in any modern model, including self-hosted Qwen-Image and Z-Image in ComfyUI. SDXL/Pony checkpoints prefer tag lists, so shorten them into tags there. Midjourney does not allow adult content.
