## 이 저장소를 만든 이유

대부분의 NSFW 프롬프트 목록은 Stable Diffusion 시절의 태그 나열입니다. 최신 이미지 모델(Qwen Image, Seedream, Z-Image)은 태그가 아니라 **완전한 문장** 형태의 프롬프트를 잘 읽습니다. 누가, 무엇을 입고, 어디에 있는지, 빛은 어떤지, 렌즈는 무엇인지를 문장으로 쓰는 것입니다. 여기 있는 모든 프롬프트는 그렇게 작성했고, 다음 정보가 함께 붙어 있습니다.

- SpicyAPI가 공개한 테스트 결과를 바탕으로 고른 작성 대상 **모델**
- 정확한 **설정**: 화면비, 해상도 또는 크기, 사용한 경우 LoRA
- 현재 카탈로그 가격 기준 **이미지 1장 비용**
- 왜 잘 되는지 설명하는 **팁**

팁은 실용적인 가이드이며 벤치마크 결과가 아닙니다. 실제 결과물이 있는 부분은 [쇼케이스](#쇼케이스-실제-결과물과-프롬프트)입니다.

레퍼런스 이미지의 룩을 재현하고 싶다면, 아래 순서대로 묘사하기만 하면 그대로 프롬프트가 됩니다.

1. **샷:** 인물 사진, 전신, 클로즈업, 오버헤드, POV, 와이드.
2. **피사체:** 성인, 나이대, 체형, 머리, 표정. 실존하는 식별 가능한 인물은 절대 묘사하지 마세요.
3. **의상:** 옷의 종류, 소재, 색, 입은 방식(앞을 연 상태, 오프숄더).
4. **포즈:** 손의 위치, 체중이 실린 곳, 시선 방향.
5. **배경:** 공간, 소품, 시간대.
6. **빛:** 광원, 방향, 색온도, 강한 빛인지 부드러운 빛인지.
7. **카메라:** 렌즈 화각, 피사계 심도, 필름 종류 또는 스마트폰 느낌.
8. **스타일:** 실사, 에디토리얼, 필름 누아르, 애니메이션(이 경우 LoRA 추가), 유화.

또는 글로 쓴 묘사를 아래의 [LLM 프롬프트 작성기](#llm에게-프롬프트-맡기기)에 붙여 넣으세요. 캐릭터나 의상을 정확히 유지하고 싶다면 프롬프트를 새로 쓰지 말고, 이미지 자체를 레퍼런스로 넣어 [편집 프롬프트](#무검열-이미지-편집-프롬프트)를 쓰세요(본인, 서로 동의한 성인, 생성한 캐릭터의 이미지에만 해당).

## 치트시트

**렌즈와 카메라**

| 이렇게 쓰세요 | 효과 |
|---|---|
| `85mm, shallow depth of field` | 인물을 돋보이게 하는 초상, 흐린 배경 |
| `35mm film` | 자연스럽고 다큐멘터리 같은 느낌, 약한 그레인 |
| `50mm` | 중립적, 눈으로 보는 것과 같은 원근감 |

| `smartphone photo, slight grain` | 실제 같은 크리에이터 콘텐츠 |

**빛**

**룩과 스타일** (프롬프트에 그대로 쓰세요): editorial fashion photography · boudoir photography · fine-art nude photography · Kodachrome / Portra 400 film · black and white · film noir · 1950s pin-up · oil painting · watercolor anime (LoRA) · storybook anime illustration (LoRA) · cyberpunk.

## 60초 만에 프롬프트 실행하기

**코드 없이:** 원하는 프롬프트를 [SpicyAPI Studio 무검열 AI 이미지 생성기](https://spicyapi.ai/ko/create/uncensored-ai-image-generator?utm_source=github&utm_medium=repo&utm_campaign=2026-09-nsfw-ai-image-prompts&utm_content=run-ko)에 붙여 넣고, 생성 전에 가격을 확인하세요.

**cURL:**

```bash
export SPICY_API_KEY="sk-spicy-..."   # https://spicyapi.ai/ko/console

curl -s https://api.spicyapi.ai/api/v1/jobs/createTask \
  -H "Authorization: Bearer $SPICY_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
    "model": "alibaba/qwen-image-2.1/text-to-image",
    "input": {
      "prompt": "Photorealistic boudoir portrait of a woman in her early 30s in black lace lingerie, soft window light from the left, 85mm, natural skin texture",
      "aspect_ratio": "2:3",
      "resolution": "1k"
    }
  }'

# data.state가 "succeeded"가 될 때까지 폴링한 뒤 data.output.assets[0].url을 다운로드
curl -s "https://api.spicyapi.ai/api/v1/jobs/recordInfo?taskId=TASK_ID" \
  -H "Authorization: Bearer $SPICY_API_KEY"
```

**LoRA로 애니메이션 만들기** (Qwen Image 2.1 LoRA): `input`에 `"loras": [{"path": "https://huggingface.co/neonforestmist/qwen-image-2512-storybook-anime-lora/resolve/main/qwen_image_2512_storybook_anime_lora.safetensors", "scale": 1}]`를 추가하고 `"model": "alibaba/qwen-image-2.1-lora/text-to-image"`를 사용하세요.

**편집** (Qwen Image 2.1 Edit): `"model": "alibaba/qwen-image-2.1/edit"`를 사용하고, `"image_urls": ["https://.../your-image.jpg"]`와 함께 편집 지시문을 `prompt`에 넣으세요.

에이전트에게 맡기고 싶다면 Claude Code, Cursor, Codex에 **[nsfw-ai-skill](https://github.com/Spicy-API/nsfw-ai-skill/blob/main/README.ko.md)** 스킬을 설치하고 이렇게 요청하세요: *"nsfw-ai-image-prompts의 B01 프롬프트를 Qwen Image 2.1로 생성해 줘"*.

## 자주 묻는 질문 (FAQ)

### NSFW 이미지 생성에 가장 좋은 AI 모델은?
SpicyAPI 공개 테스트 기준 추천은 다음과 같습니다. 대부분의 작업: **Qwen Image 2.1** (Spicy Index 73, Freedom 96.3, $0.024부터). 나만의 스타일: **Qwen Image 2.1 LoRA** (이미지 인덱스 1위), **MiniMax H3 Image LoRA** (Freedom 100). 실제 촬영한 듯한 마감: **Seedream 5.0 Pro**. 이미지에 글자가 들어갈 때: **Qwen Image 3.0 Pro**. 가장 저렴한 초안: **Z-Image Spicy**. [NSFW 이미지에 가장 좋은 모델](#nsfw-이미지에-가장-좋은-모델)을 참고하세요.

### NSFW AI 이미지 프롬프트는 어떻게 잘 쓰나요?
샷, 나이를 명시한 성인 피사체, 의상과 소재, 포즈, 배경, 빛, 렌즈, 스타일 순서로 완전한 문장을 쓰세요. 광원과 렌즈를 명시하고, "8k masterpiece" 같은 표현은 빼세요. [NSFW 이미지 프롬프트 작성법](#nsfw-이미지-프롬프트-작성법)을 참고하세요.

### 무검열 AI 이미지 편집기로 사진을 편집할 수 있나요?
네. Qwen Image 2.1 Edit에 레퍼런스 이미지 1–10장과 지시문 하나("change the outfit to…", "relight to candlelight…")를 보내면 됩니다. 본인, 서로 동의한 성인, 생성한 캐릭터의 이미지만 편집하세요. 실존 인물의 사진을 "탈의"시키는 것은 금지되어 있습니다. [편집 프롬프트](#무검열-이미지-편집-프롬프트)를 참고하세요.

### 애니메이션이나 헨타이 스타일 이미지는 어떻게 만드나요?
Qwen Image 2.1 LoRA에 공개 애니 LoRA(SpicyAPI 자체 예시에 쓰인 storybook-anime, watercolor-anime LoRA)를 함께 쓰고, 프롬프트를 LoRA의 스타일 문구로 시작하며, 모든 캐릭터를 성인으로 디자인하세요. [애니메이션 & 일러스트](#애니메이션--일러스트-qwen-image-21-lora)를 참고하세요.

### 이 프롬프트를 Stable Diffusion, ComfyUI, Midjourney에서도 쓸 수 있나요?
문장형 프롬프트는 ComfyUI에서 셀프 호스팅한 Qwen-Image와 Z-Image를 포함해 최신 모델이라면 어디서든 작동합니다. SDXL/Pony 체크포인트는 태그 나열을 선호하므로, 그런 환경에서는 태그로 줄여서 쓰세요. Midjourney는 성인 콘텐츠를 허용하지 않습니다.

### NSFW AI 이미지 생성 비용은 얼마인가요?
SpicyAPI 기준(2026-09-27): Z-Image Spicy $0.01235, Qwen Image 2.1 $0.024(1k), Qwen Image 2.1 LoRA $0.03, Seedream 5.0 Pro $0.036, Qwen Image 3.0 Pro $0.04, Qwen Image 2.1 Edit $0.036. 구독이 필요 없고, 실패한 이미지는 환불됩니다.

### NSFW 이미지 프롬프트 생성기가 있나요?
[LLM 시스템 프롬프트](#llm에게-프롬프트-맡기기)를 아무 채팅 모델에서나 쓰거나, [이미지 투 프롬프트 체크리스트](#nsfw-이미지에서-프롬프트-추출하기)로 레퍼런스 이미지를 묘사하세요.
