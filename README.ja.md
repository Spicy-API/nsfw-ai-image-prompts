## このリポジトリについて

NSFW プロンプトのリストの多くは、Stable Diffusion 時代のタグを並べただけのものです。いまの画像モデル（Qwen Image、Seedream、Z-Image）は**ちゃんとした文章**を読み取ります。誰が、何を着て、どこにいて、どんな光で、どのレンズで撮るのか。ここにあるプロンプトはすべてその書き方で書かれていて、次の情報が付いています。

- 想定している**モデル**（SpicyAPI が公開しているテスト結果から選んだもの）
- 正確な**設定**（アスペクト比、解像度またはサイズ、使う場合は LoRA）
- 現在のカタログ価格での **1 枚あたりの費用**
- なぜうまくいくのかを説明する**コツ**

コツは実践的なアドバイスで、ベンチマーク結果ではありません。実際の出力を載せているのは、このリポジトリの[ショーケース](#ショーケース-実際の出力とプロンプト)の部分です。


## NSFW 画像からプロンプトを作る

参考画像の雰囲気を再現したいときは、次の順番で説明を書けば、それがそのままプロンプトになります。

1. **ショット：** ポートレート、全身、クローズアップ、真上から、POV、引きの画。
2. **被写体：** 成人、年齢層、体型、髪、表情。実在の特定できる人物は絶対に書かないでください。
3. **服装：** 服の種類、布地、色、着方（前を開ける、肩を出す）。
4. **ポーズ：** 手はどこにあるか、重心はどこか、視線はどこを向いているか。
5. **場所：** 部屋、小道具、時間帯。
6. **光：** 光源、方向、色温度、硬い光か柔らかい光か。
7. **カメラ：** レンズの焦点距離、被写界深度、フィルムの種類やスマホで撮ったような質感。
8. **スタイル：** フォトリアル、エディトリアル、フィルムノワール、アニメ（その場合は LoRA を追加）、油絵。

書いた説明を、下の [LLM 用のプロンプト作成システムプロンプト](#llm-にプロンプトを書かせる)に貼り付けてもかまいません。キャラクターや服装をそのまま残したいなら、プロンプトを書かずに、その画像自体を参照画像にして[編集プロンプト](#無修正の画像編集プロンプト)を使ってください（自分自身、同意した成人、生成したキャラクターの画像に限ります）。

## 早見表

**レンズとカメラ**

| 書き方 | 効果 |
|---|---|
| `85mm, shallow depth of field` | きれいに見えるポートレート、背景がぼける |
| `35mm film` | 自然でドキュメンタリー風、軽い粒子感 |
| `50mm` | ニュートラルで、肉眼に近い遠近感 |
| `macro` | レース、アクセサリー、肌の極端なディテール |
| `wide shot, 24mm` | 周りの環境を見せ、人物は小さく写る |
| `overhead / top-down` | グラフィカルで平面的。ベッドやお風呂に最適 |
| `POV` | 一人称視点で、個人的な雰囲気 |
| `smartphone photo, slight grain` | 本物らしいクリエイターのコンテンツ |

**光**

| 雰囲気 | 書き方 |
|---|---|
| 柔らかく、ロマンチック | window light, sheer curtains, golden hour |
| ドラマチック | single hard key light, deep shadows, chiaroscuro |
| ノワール | slatted light from blinds, black and white |
| 温かく、親密 | candlelight, firelight, tungsten lamp |
| 華やか | softbox, beauty dish, high key |
| ネオン | magenta and cyan neon, wet reflections |
| 逆光 | rim light, silhouette, glowing edges |

**見た目とスタイル**：editorial fashion photography · boudoir photography · fine-art nude photography · Kodachrome / Portra 400 film · black and white · film noir · 1950s pin-up · oil painting · watercolor anime (LoRA) · storybook anime illustration (LoRA) · cyberpunk。

**リアルさ**：natural skin texture · visible pores · slight film grain · imperfect lived-in room · mixed practical light。「flawless」「perfect skin」「8k」はプラスチックのような見た目になりやすいので避けてください。

```bash
export SPICY_API_KEY="sk-spicy-..."   # https://spicyapi.ai/ja/console

      "resolution": "1k"

curl -s "https://api.spicyapi.ai/api/v1/jobs/recordInfo?taskId=TASK_ID" \

```

**LoRA を使ったアニメ**（Qwen Image 2.1 LoRA）：`input` に `"loras": [{"path": "https://huggingface.co/neonforestmist/qwen-image-2512-storybook-anime-lora/resolve/main/qwen_image_2512_storybook_anime_lora.safetensors", "scale": 1}]` を追加し、`"model": "alibaba/qwen-image-2.1-lora/text-to-image"` を使います。

## LLM にプロンプトを書かせる

次のシステムプロンプトを好きなチャットモデルに貼り付けてください（SpicyAPI では、成人向けの文章のテストで [Grok 4.7](https://spicyapi.ai/ja/models/grok-4-7?utm_source=github&utm_medium=repo&utm_campaign=2026-09-nsfw-ai-image-prompts&utm_content=llm-ja) と [Grok 4.3](https://spicyapi.ai/ja/models/grok-4-3?utm_source=github&utm_medium=repo&utm_campaign=2026-09-nsfw-ai-image-prompts&utm_content=llm-ja) のスコアがいちばん高くなりました）。

```text
You write prompts for adult text-to-image models. Every character is an adult aged 21 or older; never use
descriptors that suggest youth and never depict real, identifiable people.
Given a short idea (or a description of a reference image), return ONE prompt of 40–90 words in this order:
shot type, subject (with adult age), wardrobe and fabric, pose and hands, setting, light source and direction,
lens or film look, style. Use natural sentences, not tag lists. Put any on-image text in quotes.
```

## よくある質問

### NSFW 画像の生成におすすめの AI モデルは？
SpicyAPI が公開しているテストでは、ほとんどの用途には **Qwen Image 2.1**（Spicy Index 73、Freedom 96.3、$0.024 から）、自分のスタイルを使うなら **Qwen Image 2.1 LoRA**（画像の Index で 1 位）と **MiniMax H3 Image LoRA**（Freedom 100）、写真らしい仕上がりなら **Seedream 5.0 Pro**、画像に文字が入るなら **Qwen Image 3.0 Pro**、いちばん安い下書きなら **Z-Image Spicy** です。[NSFW 画像におすすめのモデル](#nsfw-画像におすすめのモデル)を参照してください。

### NSFW AI 画像のプロンプトはどう書けばいい？
ショット、年齢付きの成人の被写体、服装と布地、ポーズ、場所、光、レンズ、スタイルの順に、ちゃんとした文章で書きます。光源とレンズを指定し、「8k masterpiece」のような言葉は省いてください。[NSFW 画像プロンプトの書き方](#nsfw-画像プロンプトの書き方)を参照してください。

### 無修正の AI 画像編集で写真を編集できる？
できます。Qwen Image 2.1 Edit に 1〜10 枚の参照画像と指示を 1 つ（「change the outfit to…」「relight to candlelight…」など）送ってください。編集してよいのは、自分自身、同意した成人、生成したキャラクターの画像だけです。実在の人物の写真を「脱がせる」ことは禁止です。[編集プロンプト](#無修正の画像編集プロンプト)を参照してください。

### アニメやエロアニメ風の画像はどうやって作る？
Qwen Image 2.1 LoRA とオープンなアニメ LoRA（SpicyAPI 自身の例で使われている storybook-anime と watercolor-anime の LoRA）を使い、プロンプトを LoRA のスタイルフレーズから始め、どのキャラクターも成人としてデザインしてください。[アニメ & イラスト](#アニメ--イラストqwen-image-21-lora)を参照してください。

### このプロンプトは Stable Diffusion、ComfyUI、Midjourney でも使える？
文章形式のプロンプトは、ComfyUI でセルフホストした Qwen-Image や Z-Image を含め、最近のモデルならどれでも使えます。SDXL や Pony のチェックポイントはタグの羅列を好むので、そこではタグに短くしてください。Midjourney は成人向けコンテンツを許可していません。

### NSFW AI 画像は 1 枚いくら？
SpicyAPI（2026-09-27）では、Z-Image Spicy $0.01235、Qwen Image 2.1 $0.024（1k）、Qwen Image 2.1 LoRA $0.03、Seedream 5.0 Pro $0.036、Qwen Image 3.0 Pro $0.04、Qwen Image 2.1 Edit $0.036 です。サブスクリプションは不要で、失敗した画像は返金されます。

### NSFW 画像のプロンプト生成ツールはある？
[LLM 用のシステムプロンプト](#llm-にプロンプトを書かせる)を好きなチャットモデルで使うか、[画像からプロンプトを作るチェックリスト](#nsfw-画像からプロンプトを作る)で参考画像を説明してください。
